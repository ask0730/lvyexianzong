# vue3-node

vue3-node full stack project

## web-admin

vue3 + ts + elementplus + pinia 管理系统系统

```bash
npm i
npm run dev
```

## web-company

vue3 + ts + elementplus 门户网站

```bash
npm i
npm run dev
```

## web-server

nodeJS express 后台接口

演示需要连接本地 mongodb 数据库，在 mongodb bin 目录执行：mongod.exe --dbpath=E:\Users\Ask\Desktop\db [--dbpath=你的本地地址不能有中文]

```bash
npm i
npm start
```
