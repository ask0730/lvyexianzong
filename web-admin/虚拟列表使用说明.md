# 虚拟列表组件使用说明

## 概述

虚拟列表组件 (`VirtualTable.vue`) 是一个高性能的表格组件，专门用于处理大量数据的展示。它通过虚拟滚动技术，只渲染可见区域的数据，从而显著提升页面性能。

## 主要特性

- 🚀 **高性能**: 虚拟滚动，只渲染可见数据
- 🔍 **搜索功能**: 内置搜索框，支持多列搜索
- 📊 **排序功能**: 支持点击列头排序
- 🎨 **美观界面**: 现代化设计，渐变表头
- 📱 **响应式**: 自适应不同屏幕尺寸
- ⚡ **流畅交互**: 平滑的滚动和动画效果

## 基本用法

```vue
<template>
  <VirtualTable 
    :data="tableData" 
    :columns="columns"
    :row-height="60"
    :buffer-size="10"
    item-key="id"
    :loading="loading"
    :searchable="true"
    :sortable="true"
    @search="handleSearch"
    @sort="handleSort"
    @row-click="handleRowClick"
  >
    <!-- 自定义列内容 -->
    <template #category="{ row }">
      {{ getCategoryLabel(row.category) }}
    </template>
    
    <template #actions="{ row }">
      <el-button @click="handleEdit(row)">编辑</el-button>
    </template>
  </VirtualTable>
</template>

<script setup>
import VirtualTable from '@/components/VirtualTable.vue'

const columns = [
  {
    prop: 'title',
    label: '标题',
    width: '300px',
    sortable: true,
    searchable: true
  },
  {
    prop: 'category',
    label: '分类',
    width: '120px',
    slot: 'category'
  },
  {
    prop: 'actions',
    label: '操作',
    width: '200px',
    slot: 'actions'
  }
]
</script>
```

## Props 参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| data | Array | [] | 表格数据 |
| columns | Array | [] | 列配置 |
| rowHeight | Number | 50 | 行高度 |
| bufferSize | Number | 5 | 缓冲区大小 |
| itemKey | String/Function | 'id' | 唯一键 |
| showToolbar | Boolean | true | 是否显示工具栏 |
| showSearch | Boolean | true | 是否显示搜索框 |
| showPaginationInfo | Boolean | true | 是否显示分页信息 |
| loading | Boolean | false | 加载状态 |
| searchable | Boolean | true | 是否启用搜索 |
| sortable | Boolean | true | 是否启用排序 |

## 列配置 (columns)

```javascript
const columns = [
  {
    prop: 'title',           // 数据字段名
    label: '标题',           // 列标题
    width: '300px',          // 列宽度
    minWidth: '200px',       // 最小宽度
    slot: 'title',           // 自定义插槽名
    sortable: true,          // 是否可排序
    searchable: true         // 是否可搜索
  }
]
```

## 事件

| 事件名 | 参数 | 说明 |
|--------|------|------|
| search | keyword: string | 搜索事件 |
| sort | column: string, order: 'asc'/'desc' | 排序事件 |
| row-click | item: any, index: number | 行点击事件 |

## 插槽

### 默认插槽
用于自定义列内容，插槽名为 `slot` 属性指定的值。

```vue
<template #category="{ row, index }">
  <el-tag>{{ row.category }}</el-tag>
</template>
```

## 方法

通过 ref 可以调用以下方法：

```javascript
const virtualTableRef = ref()

// 滚动到指定索引
virtualTableRef.value.scrollToIndex(100)

// 滚动到顶部
virtualTableRef.value.scrollToTop()

// 刷新表格
virtualTableRef.value.refresh()
```

## 性能优化建议

1. **合理设置行高**: 根据内容设置合适的 `rowHeight`
2. **调整缓冲区**: 根据滚动性能调整 `bufferSize`
3. **使用唯一键**: 确保 `itemKey` 的唯一性
4. **避免频繁更新**: 减少不必要的数据更新

## 注意事项

1. 确保数据有唯一的 `itemKey`
2. 列配置中的 `prop` 要与数据字段对应
3. 自定义插槽需要指定 `slot` 属性
4. 大量数据时建议启用虚拟滚动
