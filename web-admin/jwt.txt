登录认证：
1. Branca
Go语言实现，XChaCha20算法提供安全保障。遵循自己的token规范，构建RESTful API和web应用
2. Sa-Token
安全框架，支持整合Redis，前后端分离，零配置开箱即用，简化权限认证
3. gtoken
实现SSO登录的框架，提供服务端缓存自动续期，不通过refresh_token刷新token，解决了JWT无法在服务端主动退出和无法作废已颁布令牌的问题
4. OAuth 2.0
授权框架，允许三方应用获取访问权限，无需提供密码，可以与JWT结合使用
5. CAS（Central Authentication Service）和SAML（Security Assertion Markup Language）
实现单点登录（SSO）的技术，支持跨多应用身份验证和授权
代码
 在Vue 3项目中结合Pinia进行用户登录状态验证和权限管理，并使用JWT（JSON Web Tokens）作为身份验证机制，您可以按照以下步骤进行实现：

### 1. 安装必要的依赖
确保您的Vue 3项目中安装了`pinia`和`axios`。

```bash
npm install pinia axios
```

### 2. 配置Pinia状态管理
创建一个Pinia store来管理用户的登录状态和JWT。

```javascript
// store/auth.js
import { defineStore } from 'pinia'

export const useAuthStore = defineStore('auth', {
  state: () => ({
    token: null,
    userInfo: null,
    isAuthenticated: false,
  }),
  actions: {
    login(credentials) {
      // 发送请求到后端进行登录
      // 假设使用axios发送请求
      axios.post('/api/login', credentials)
        .then(response => {
          this.token = response.data.token
          this.userInfo = response.data.user
          this.isAuthenticated = true
        })
        .catch(error => {
          // 处理登录错误
        })
    },
    logout() {
      // 清除token和用户信息
      this.token = null
      this.userInfo = null
      this.isAuthenticated = false
    },
    // 其他与认证相关的方法
  },
})
```

### 3. 设置Vue Router路由守卫
在Vue Router中配置路由守卫，以保护需要认证的路由。

```javascript
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import { useAuthStore } from '../store/auth'

const router = createRouter({
  // ...路由配置
})

router.beforeEach((to, from, next) => {
  const authStore = useAuthStore()
  if (to.meta.requiresAuth && !authStore.isAuthenticated) {
    next('/login') // 如果需要认证但用户未登录，重定向到登录页
  } else {
    next() // 否则允许访问
  }
})

export default router
```

### 4. 配置Axios请求拦截器
在应用的入口文件（如`main.js`）中配置Axios请求拦截器，以便在每个请求中自动添加JWT。

```javascript
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router/index'
import { createPinia } from 'pinia'
import piniaPersist from 'pinia-plugin-persist'
import axios from 'axios'

const app = createApp(App)

const pinia = createPinia()
pinia.use(piniaPersist)

app.use(router)
app.use(pinia)

// 配置Axios
const service = axios.create({
  baseURL: '/api',
  timeout: 5000,
})

service.interceptors.request.use(config => {
  const authStore = useAuthStore()
  if (authStore.token) {
    config.headers.Authorization = `Bearer ${authStore.token}`
  }
  return config
}, error => {
  return Promise.reject(error)
})

app.provide('axios', service)

app.mount('#app')
```

### 5. 实现登录和登出功能
在登录组件中，使用`useAuthStore`的`login`方法来处理用户登录逻辑。在登出组件中，使用`logout`方法来清除用户的登录状态和JWT。

```javascript
// components/Login.vue
<script setup>
import { useAuthStore } from '../store/auth'

const authStore = useAuthStore()

const handleLogin = () => {
  // 获取用户输入的用户名和密码
  // 调用authStore.login进行登录
}
</script>

// components/Logout.vue
<script setup>
import { useAuthStore } from '../store/auth'

const authStore = useAuthStore()

const handleLogout = () => {
  authStore.logout()
}
</script>
```
